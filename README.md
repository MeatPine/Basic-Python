# Basic Python

Решения задач по основам Python.

- sem1 - это 10 заданий с 1-ого семинара (вариант 1)
- sem4 - это 25 заданий с 4-ого семинара

Условия заданий находятся в соответствующих папках.
Каждый Python-файл запускается отдельно.

## Зависимости

Для задачи 5 из sem1 используется NumPy,
для задач 6 и 7 — Faker.
Остальные задачи используют стандартную библиотеку Python.

Установка зависимостей:

    python -m pip install numpy Faker

## Входные данные

В sem1 задачи 6 и 7 самостоятельно создают тестовые файлы.
При повторном запуске эти файлы перезаписываются.

Для файловых задач sem4 нужны входные файлы с именами,
указанными в коде. Они читаются из текущей папки запуска.
В задачах 06 и 07 путь к папке вводится пользователем.
