# Набор заданий по основам Python

## Общие требования

Если в условии не указано иное:

* использовать Python 3;
* основную логику реализовывать в виде функций;
* не использовать глобальные переменные для хранения результатов;
* не использовать сторонние библиотеки, кроме явно указанных в условии;
* для проверки алгоритма самостоятельно подготовить несколько тестовых примеров;
* при работе с файлами корректно обрабатывать пустой файл и некорректные данные;
* если требуется генерация тестовых данных, генератор также должен быть реализован программно.

# Вариант 1

## Задача 1. Спиральная матрица

Требуется написать функцию, которая принимает два целых числа `n` и `m` и создает матрицу размера `n × m`, заполненную числами от `1` до `n * m` по спирали, начиная с левого верхнего угла и двигаясь по часовой стрелке.

Дополнительные требования:

* функция должна возвращать матрицу, а не печатать ее;
* матрица может быть как квадратной, так и прямоугольной;
* числа должны увеличиваться от `1` к `n * m`;
* запрещается использовать готовые функции или библиотеки для построения спирали;
* дополнительно реализовать режим заполнения от `n * m` до `1`;
* продемонстрировать работу функции для размеров `3 × 3`, `3 × 5` и `4 × 2`.

---

## Задача 2. Самая необычная строка

Требуется написать функцию, которая последовательно получает от пользователя строки до ввода специального слова `STOP` и определяет строку с наибольшим количеством различных символов.

Дополнительные требования:

* все введенные строки нельзя хранить в списке;
* после каждого ввода необходимо при необходимости обновлять текущий результат;
* регистр букв не учитывать;
* пробелы и знаки пунктуации считать символами;
* если несколько строк имеют одинаковый результат, сохранить первую из них;
* после завершения ввода вывести найденную строку и количество различных символов в ней.

---

## Задача 3. Сжатие последовательности

Требуется написать функцию, которая принимает список целых чисел и заменяет каждую группу одинаковых подряд идущих элементов парой `(значение, количество повторений)`.

Например:

```text
[1, 1, 1, 2, 2, 5, 5, 5, 5, 3]
```

должна превратиться в:

```text
[(1, 3), (2, 2), (5, 4), (3, 1)]
```

Дополнительные требования:

* не использовать `itertools.groupby`;
* порядок групп должен сохраняться;
* отдельно написать функцию обратного преобразования;
* проверить, что после сжатия и последующего восстановления получается исходный список;
* пустой список должен корректно обрабатываться.

---

## Задача 4. Ближайшая точка

Требуется написать функцию, которая принимает список двумерных точек вида `(x, y)` и координаты некоторой контрольной точки `(x0, y0)` и возвращает точку, находящуюся ближе всего к контрольной.

Дополнительные требования:

* использовать евклидово расстояние;
* не использовать сортировку;
* не создавать отдельный список расстояний;
* при одинаковом расстоянии вернуть точку, которая встретилась первой;
* дополнительно вернуть само расстояние до найденной точки;
* объяснить, почему для сравнения расстояний необязательно вычислять квадратный корень.

---

## Задача 5. Скользящее среднее

Требуется написать функцию, которая принимает список чисел и размер окна `k` и возвращает список значений простого скользящего среднего.

Например:


Дополнительные требования:

* корректно проверять значение `k`;
* после собственной реализации написать второй вариант с использованием `numpy`;
* сравнить результаты двух реализаций на одном наборе данных;
* объяснить вычислительную сложность первого варианта;
* по возможности реализовать более эффективный вариант, в котором не пересчитывается сумма всего окна с нуля.

## Задача 9. Банковский счет

Требуется реализовать систему классов для моделирования банковского счета.


* продемонстрировать полиморфизм при работе со списком разных счетов.

## Задача 9. Система доставки

Требуется реализовать систему классов для расчета стоимости доставки.

Необходимо создать базовый класс `Delivery` и классы:

```text
CourierDelivery
PostDelivery
PickupDelivery
```

Каждый способ доставки должен рассчитывать стоимость по собственным правилам.

Дополнительные требования:

* стоимость должна зависеть от веса посылки;
* курьерская доставка дополнительно зависит от расстояния;
* почтовая доставка должна иметь фиксированную базовую стоимость;
* самовывоз должен быть бесплатным;
* параметры посылки должны проверяться;
* создать класс `Order`, содержащий товары и способ доставки;
* реализовать расчет полной стоимости заказа;
* использовать полиморфизм;
* пользовательский код не должен проверять конкретный тип доставки через цепочку `if/elif`.

## Задача 10. Система обработки данных

Требуется реализовать систему классов для последовательной обработки набора числовых данных.

Необходимо создать классы:

```text
DataSource
DataFilter
DataAnalyzer
ReportGenerator
```

Система должна выполнять следующий процесс:

```text
получение данных
      ↓
фильтрация
      ↓
анализ
      ↓
формирование отчета
```

Дополнительные требования:

* `DataSource` должен уметь получать данные из списка и из текстового файла;
* `DataFilter` должен уметь удалять отрицательные значения и значения, выходящие за заданный диапазон;
* `DataAnalyzer` должен вычислять минимум, максимум, среднее и стандартное отклонение;
* `ReportGenerator` должен формировать текстовый отчет;
* классы должны взаимодействовать через понятные интерфейсы;
* реализовать как минимум два разных источника данных;
* реализовать как минимум два фильтра;
* анализатор не должен знать, откуда были получены данные;
* добавить декоратор измерения времени для этапов обработки;
* результаты отчета сохранить в отдельный файл;
* для проверки создать генератор входного файла минимум на 10 000 чисел с использованием `random`;
* отдельно проверить работу системы на маленьком заранее известном наборе данных.
